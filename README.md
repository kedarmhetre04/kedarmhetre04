### 🚀 Featured Projects

#### 🧠 AnalystOS: Agentic AI Analytics Platform

<div align="center">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=kedarmhetre04&repo=analyst-os&theme=nord&border_color=7dd3fc&title_color=7dd3fc" alt="AnalystOS"/>
</div>

A multi-agent AI analyst that answers *"why did this metric change?"* in plain English over 417K order line items, and checks its own work before it reports. **Planner, Investigator, Critic, and Reporter** agents turn a question into SQL analysis and a report a stakeholder can read.

- Built end to end with **Claude Code**: repository audits, code generation, debugging, and testing
- Read-only SQL guardrails, automatic query repair, critic-driven retries, and structured-output validation
- **3/3 correct** in a real-API evaluation. It repaired 3 failed SQL queries on its own and caught a reconciliation error
- Streamlit frontend with KPI cards, charts, and evidence views for demos

| Layer | Technology |
|---|---|
| Agents | OpenAI Responses API, Tool Calling, Structured Outputs |
| Data | DuckDB, SQL |
| Frontend | Streamlit |
| Build | Claude Code (AI-assisted development) |
